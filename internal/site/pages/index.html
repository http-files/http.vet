A release of .http is a selection of features. This page reads down each selection and asks whether it holds: a column every client clears is a year's wording that has settled, and a ragged one is a year still being argued. The last column is every feature no release has claimed — where the disagreement that decides the next selection is still visible.

Results come from httpvet. Each report embeds the wire evidence its client produced, and every state on this page is derived from that evidence by the kit's current check scripts when the page is built. A report is the record; the scripts are the present.
